V1.0 screenshots showed an almost-black entry and premature black exit despite passing checkpoint QA. V1.1 separates three reversible triggers: entry (top bottom → top top, opacity only, original edge stagger), pin (150% desktop, 100% compact, scale .70/.72, skew 5/3, title entry, 26% appreciation hold), exit (next section top bottom → top 15%, independent black overlay). Stable 100svh stage; pin length based on stage height, not mobile browser toolbar-dependent innerHeight. Same nine photographs, same H2, same typography and identity. No modifications to library originals, other sections or Services content. Physical iPhone and Android validation is distinct from browser emulation.

## Refinement V1.2 — deterministic integration
V1.1 was deployed despite continuous-scroll QA failure (run 45835957210, five failed cases). The measured offsets match the height growth of upstream ATZ-SEC-002 after asynchronous native mounting. The cinematic module now awaits the shared nativeComponentsReady promise, document fonts, and two animation frames before creating its triggers. A scoped ResizeObserver refreshes on upstream geometry changes; resize and pageshow refresh as well. No arbitrary delay or vendor changes. Entry adds distinct x/y edge movement while pin exclusively owns scale/skew, retaining the V1.1 durations, photography, typography and exit. QA retains all prior acceptance assertions and adds actual pin-spacer/start, prior section boundary, pinned stage and exit geometry checks. Physical mobile-device approval and visual acceptance remain separate.
